# Bosses

## 1. Mid Boss Schedule

성장 구간 중 총 3회의 중간 보스가 등장한다.

- Mid Boss 1: `2:30`
- Mid Boss 2: `5:00`
- Mid Boss 3: `7:30`

## 2. Mid Boss Common Rules

- 각 중간 보스는 일반 적 1, 2, 3의 진화형으로 설계한다.
- 이전 중간 보스가 살아 있어도 다음 중간 보스는 예정된 시간에 등장한다.
- 여러 중간 보스가 동시에 존재할 수 있다.
- 중간 보스 등장 중에도 일반 적 스폰량과 스폰 주기를 변경하지 않는다.
- 중간 보스는 기본 공격과 폭탄의 넉백에 면역이다.
- 데미지 숫자와 화면 상단 전용 HP Bar를 표시한다.
- 여러 중간 보스가 존재하면 각각의 HP Bar를 세로로 표시한다.

## 3. Mid Boss 1 - Melee Evolution

근접형 일반 적의 진화형.

- 기본 근접 추적과 접촉 공격 특성을 유지한다.
- 추가 패턴으로 돌진 공격을 사용한다.

### Charge Attack

1. 패턴 시작 시 플레이어의 현재 위치를 기준으로 돌진 방향을 결정한다.
2. 예고가 시작되는 순간 돌진 방향을 고정한다.
3. 돌진할 공격 범위를 바닥에 표시한다.
4. 표시된 범위가 시간에 따라 점점 차오른다.
5. 범위가 완전히 차면 표시된 방향으로 돌진한다.
6. 돌진 중에는 방향을 변경하지 않는다.
7. 돌진 종료 후 짧은 후딜레이를 가진다.
8. 이후 기본 근접 추적으로 복귀한다.

## 4. Mid Boss 2 - Ranged Evolution

원거리형 일반 적의 진화형.

- 기본 직선 투사체 공격 특성을 유지한다.
- 추가 패턴으로 3회 연속 조준 사격을 사용한다.

### Aimed Burst

각 사격마다 다음 과정을 수행한다.

1. 플레이어의 현재 위치를 새로 조준한다.
2. 탄환이 이동할 궤적을 미리 표시한다.
3. 처음에는 흐린 조준선으로 표시한다.
4. 발사 시간이 가까워질수록 조준선이 선명해진다.
5. 발사 직전 조준선을 짧게 점멸시킨다.
6. 표시된 궤적을 따라 직선 투사체를 발사한다.
7. 위 과정을 총 3회 반복한다.

각 탄환은 발사 후 플레이어를 추적하지 않는다.

## 5. Mid Boss 3 - Shield Evolution

재생 보호막형 일반 적의 진화형.

- 전투 시작 시 보호막 3스택을 가진다.
- 보호막이 존재하는 동안 공격을 받을 때마다 해당 공격 피해를 무효화하고 1스택을 소모한다.
- 보호막 3스택이 모두 파괴되면 그로기 상태에 진입한다.

### Groggy State

- 제자리에서 이동과 공격을 중단한다.
- 어지러워하는 시각적 연출을 표시한다.
- 그로기 중에는 보호막 없이 모든 공격 피해를 정상적으로 받는다.
- 그로기 중에는 보호막 재생 타이머가 진행되지 않는다.
- 일정 시간이 지나면 그로기가 종료된다.
- 종료 시 보호막 3스택을 한꺼번에 복구하고 정상 전투로 돌아간다.

구체적인 그로기 시간은 플레이테스트로 조정한다.

## 6. Mid Boss Rewards

중간 보스를 정상적으로 처치하면:

- 여러 개의 경험치 오브젝트를 주변에 드롭한다.
- 리롤 아이템 1개를 드롭한다.
- 리롤 아이템은 플레이어가 직접 획득해야 한다.
- 리롤 아이템의 추적 및 획득 규칙은 경험치 오브젝트와 동일하다.

10분 전환으로 강제 제거된 중간 보스는 경험치, 리롤 아이템, 처치 점수를 제공하지 않는다.

## 7. Final Boss Common Behavior

최종 보스는 세 일반 적 및 중간 보스 계열의 특징을 조합한 3페이즈 전투로 구성한다.

### Chase and Melee

- 특수 패턴을 사용하지 않을 때 플레이어를 추적한다.
- 플레이어와 단순히 접촉하는 것만으로는 피해를 주지 않는다.
- 근접 사거리 안에 들어오면 이동을 멈추고 무기 휘두르기를 준비한다.
- 짧은 예고 후 공격 방향을 고정하고 전방 부채꼴 범위를 한 번 공격한다.
- 공격 후 짧은 후딜레이를 가진다.
- 근접 공격의 속도와 범위는 모든 페이즈에서 동일하다.

### Basic Combat Cycle

1. 일정 시간 플레이어를 추적한다.
2. 가까우면 근접 휘두르기를 사용한다.
3. 특수 패턴 쿨타임이 끝나면 거리와 관계없이 해당 페이즈의 특수 패턴을 시작한다.
4. 특수 패턴 종료 후 딜타임을 가진다.
5. 다시 추적과 근접 공격으로 복귀한다.

정확한 추적 시간, 특수 패턴 주기, 딜타임은 플레이테스트로 조정한다.

## 8. Final Boss HP Phases

- Phase 1: HP `100% ~ 약 67%`
- Phase 2: HP `약 67% ~ 약 34%`
- Phase 3: HP `약 34% 이하`
- 최종 보스 HP Bar에 두 개의 페이즈 구분선을 표시한다.
- 정확한 비율은 플레이테스트로 조정할 수 있다.

### Phase Transition Gate

- 구분선에 도달하면 HP를 해당 경계에서 잠근다.
- 경계를 넘는 초과 피해는 다음 페이즈로 이월하지 않는다.
- 진행 중인 공격을 취소한다.
- 짧은 전환 연출 동안 무적 상태가 된다.
- 전환 완료 후 다음 페이즈를 시작한다.
- 페이즈 변화는 큰 변신 대신 적당한 오라, 색상, 효과음으로 구분한다.
- Phase 3 진입 시 보호막 3겹 생성이 명확한 시각적 구분이 된다.

## 9. Final Boss Phase 1

근접 및 돌진 계열 중심의 첫 페이즈.

### Double Charge

1. 플레이어 위치를 조준하고 공격 범위를 예고한다.
2. 예고가 시작되면 방향을 고정하고 1회 돌진한다.
3. 짧게 멈춘 뒤 플레이어 위치를 다시 조준한다.
4. 새 방향을 예고하고 2회차 돌진을 사용한다.
5. 두 번째 돌진이 끝나면 짧은 딜타임을 가진다.

## 10. Final Boss Phase 2

돌진과 원거리 조준 사격을 하나의 연계 패턴으로 조합한다. Phase 1의 2회 연속 돌진은 별도 패턴으로 유지하지 않는다.

### Alternating Charge and Shot

1. 플레이어 위치를 조준하고 예고 후 1회 돌진한다.
2. 플레이어 위치를 새로 조준하고 조준선 예고 후 직선 투사체 1발을 발사한다.
3. 위 `돌진 1회 → 조준 사격 1발` 과정을 총 3회 반복한다.
4. 연계가 끝나면 Phase 1보다 긴 딜타임을 가진다.

- 각 돌진과 사격은 플레이어 위치를 새로 조준한다.
- 각 예고가 시작되면 해당 공격 방향은 고정된다.
- 발사된 탄환은 플레이어를 추적하지 않는다.

## 11. Final Boss Phase 3

Phase 2의 연계 공격을 유지하면서 속도와 보호막 공략을 추가한다.

### Offensive Changes

- 돌진 이동 속도를 Phase 2보다 소폭 증가시킨다.
- 조준선이 차오르는 시간을 소폭 단축한다.
- 탄환 이동 속도는 Phase 2와 동일하게 유지한다.
- 연계 구조와 예고 규칙은 변경하지 않는다.

### Three-layer Shield

- Phase 3 진입 시 HP를 가진 보호막 3겹을 생성한다.
- 각 보호막은 별도의 HP를 가진다.
- 모든 피해는 현재 가장 바깥쪽 보호막에만 적용된다.
- 한 번의 공격은 피해량이 충분해도 최대 한 겹만 파괴할 수 있다.
- 보호막 HP를 초과한 피해는 다음 보호막이나 본체로 이월하지 않는다.
- 보호막이 한 겹이라도 남아 있으면 보스 본체 HP는 감소하지 않는다.
- 보스 HP Bar 위에 3칸으로 분리된 보호막 Bar를 표시한다.
- 보스 주변에도 남은 보호막 겹 수를 구분할 수 있는 시각 효과를 표시한다.

### Shield Break and Groggy

- 마지막 보호막이 깨지는 순간 진행 중인 돌진 또는 사격을 즉시 취소한다.
- 보스는 즉시 그로기 상태에 진입한다.
- 그로기 중에는 이동과 공격을 중단한다.
- 보스 본체는 그로기 상태에서만 피해를 받는다.
- 그로기 딜타임은 Phase 2 연계 후 딜타임보다 길며, 최종 보스전에서 가장 긴 공격 기회다.
- 그로기 종료 시 보호막 3겹과 각 보호막 HP를 전부 복구한다.
- 이후 Phase 3 전투를 반복한다.

## 12. Final Boss Death

- HP가 0이 되는 순간 진행 중인 공격과 충돌 판정을 즉시 중단한다.
- 짧은 사망 연출을 재생한다.
- 사망 연출 종료 후 게임 시간을 정지하고 Victory 화면을 표시한다.
- 보스전 제한시간과 결과 표시는 [Stage Flow](STAGE_FLOW.md)를 따른다.
