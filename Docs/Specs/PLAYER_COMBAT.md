# Player & Combat

## 1. Movement

- 플레이어는 `WASD` 또는 방향키로 8방향 이동한다.
- 대각선 이동속도는 정규화하여 직선 이동속도와 동일하게 유지한다.
- 이동은 전투 중 플레이어의 기본 조작이다.
- 플레이어 캐릭터 설정과 최종 외형은 프로토타입 이후 결정한다.

## 2. Health

- 플레이어는 전투 시작 시 최대 HP 상태로 시작한다.
- HP가 0 이하가 되면 즉시 사망 상태로 전환한다.
- 피해를 받은 뒤 짧은 전역 무적시간을 적용하여 여러 공격에 동시에 연속 피격되는 상황을 방지한다.
- 기본 무적시간은 모든 플레이어에게 존재하며, 패시브로 증가시킬 수 있다.

### Base Regeneration

- 플레이어는 기본적으로 매우 느린 무피격 체력 재생을 가진다.
- 피해를 받으면 일정 시간 재생이 중단된다.
- 무피격 대기시간이 지나면 초당 일정량의 HP를 회복한다.
- 체력 재생 패시브는 새 기능을 해금하지 않고 기본 재생 속도를 강화한다.
- 별도의 체력 회복 아이템은 MVP에서 사용하지 않는다.

## 3. Basic Attack - Bow & Arrow

- 기본 공격은 자동으로 수행된다.
- 플레이어와 가장 가까운 적을 공격 대상으로 선정한다.
- 발사 순간 대상 방향을 고정하고 직선 화살 1발을 발사한다.
- 기본 화살은 발사 후 적을 추적하지 않는다.
- 기본 상태에서는 첫 적에게 적중하면 사라진다.
- 세부 특성은 [Weapons](WEAPONS.md)의 기본 무기 항목을 따른다.

## 4. Damage Modifiers

전역 무기 공격력 패시브와 무기별 피해 특성은 서로 다른 출처로 관리하되 합산한다.

```text
최종 피해량 = 무기 기본 피해량 × (1 + 전역 공격력 보너스 + 무기별 피해 보너스)
```

- 공격력 보너스를 서로 곱하지 않는다.
- 전역 공격속도와 무기별 공격속도도 합산한 뒤 공격 빈도에 적용한다.

```text
실제 공격 빈도 = 기본 공격 빈도 × (1 + 전역 공격속도 + 무기별 공격속도)
```

- 실제 쿨타임은 공격 빈도의 역수로 계산하여 0 또는 음수가 되지 않도록 한다.

## 5. Bomb

폭탄은 보유 개수를 소비하는 아이템이 아니라 긴 쿨타임을 가진 수동 스킬이다.

- 게임 시작 시 바로 사용 가능하다.
- 전투 중 `Space`로 사용한다.
- 사용하면 긴 쿨타임이 시작되고, 쿨타임 종료 후 다시 사용할 수 있다.
- 레벨업 또는 수동 일시정지로 게임 시간이 멈추면 폭탄 쿨타임도 멈춘다.
- 플레이어 중심의 넓은 범위에 즉시 강한 피해를 준다.
- 범위 안의 적 투사체를 제거한다.
- 일반 적에게 강한 넉백을 적용한다.
- 중간 보스와 최종 보스는 피해만 받고 넉백에는 면역이다.
- 보스의 진행 중인 특수 패턴은 취소하지 않는다.
- 최종 보스 보호막에는 일반 공격 1회로 판정되어, 피해가 충분해도 한 번에 최대 한 겹만 파괴한다.
- MVP에서는 레벨업 선택지에 등장하지 않으며 한 판 동안 성능이 고정된다.
- 무기 공격력 및 공격속도 패시브는 폭탄에 적용되지 않는다.

## 6. Death

- 플레이어 HP가 0 이하가 되는 순간 이동, 공격, 충돌을 즉시 중단한다.
- 짧은 사망 연출을 재생한 뒤 모든 게임 상태를 정지한다.
- 이후 Game Over 결과 화면을 표시한다.
- 결과 화면 규칙은 [Stage Flow](STAGE_FLOW.md)를 따른다.
