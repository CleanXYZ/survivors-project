# UI & Controls

## 1. Combat Input

- `WASD` 또는 방향키: 플레이어 8방향 이동
- `Space`: 전투 중 폭탄 사용
- `Esc`: 전투 중 수동 일시정지
- 기본 공격과 보유 무기는 자동으로 공격한다.

## 2. Player-following HUD

### Player HP

- 플레이어 머리 위에 숫자 없는 HP Bar를 상시 표시한다.
- HP Bar는 캐릭터 이동을 따라간다.
- 피해와 회복을 즉시 반영한다.
- 최대 HP 패시브를 선택하면 Bar의 전체 길이도 조금 증가한다.
- 최대 HP 증가 시 Bar 확장 애니메이션, 초록색 점멸, `MAX HP +값` 문구를 잠깐 표시한다.
- Bar가 지나치게 길어지지 않도록 최대 표시 너비를 제한한다.

### Bomb Cooldown

- HP Bar 옆에 작은 폭탄 아이콘을 표시한다.
- 아이콘 테두리의 원형 진행도로 쿨타임을 표시한다.
- 쿨타임 중에는 어둡게 표시하고, 사용 가능하면 밝아지며 짧게 점멸한다.
- 캐릭터 주변 UI 복잡도를 줄이기 위해 남은 시간 숫자는 표시하지 않는다.
- 폭탄 입력 키 안내는 게임 시작 또는 최초 사용 가능 시 잠깐 표시한다.

## 3. Persistent HUD

### Experience

- 경험치 Bar를 화면 하단에 상시 표시한다.
- 현재 Level을 경험치 UI와 함께 표시한다.
- 모든 성장 후보가 소진되면 `MAX`를 표시한다.

### Build Summary

- 화면 왼쪽 가장자리에 세로형 빌드 요약 HUD를 표시한다.
- 위쪽에 보유 무기 아이콘을 최대 4개 표시한다.
- 각 무기 아이콘 옆에 선택한 특성 수를 작은 점 4개로 표시한다.
- 무기 아래에 보유 패시브 아이콘을 세로로 표시한다.
- 패시브 아이콘에 현재 단계를 숫자로 표시한다.
- 전투 HUD에서는 이름과 상세 설명을 표시하지 않는다.

### Timer, Score, and Boss HP

화면 12시 방향 상단 중앙을 다음 순서로 구성한다.

1. 성장 경과 시간 또는 최종 보스 남은 시간
2. 타이머 옆의 작은 현재 점수
3. 중간 보스 또는 최종 보스 HP Bar

- 중간 보스가 여러 마리면 각각의 HP Bar를 아래쪽으로 쌓는다.
- 중간 보스가 사망하면 해당 HP Bar를 제거한다.
- 최종 보스 HP Bar에는 페이즈 구분선 두 개를 표시한다.
- Phase 3에서는 최종 보스 HP Bar 위에 3분할 보호막 Bar를 표시한다.
- 보스 제한시간이 얼마 남지 않으면 타이머 색상 변화와 점멸을 사용한다.

## 4. Level Up Screen

- 레벨업 조건을 충족하면 게임 시간을 정지하고 선택 화면을 표시한다.
- 서로 다른 성장 선택지 최대 3개를 표시한다.
- 각 선택지에는 개별 리롤 버튼을 표시한다.
- 보유 리롤 횟수를 화면에 표시한다.
- 현재 빌드 요약을 확장해 무기별 선택 특성 이름과 패시브 효과 및 단계를 자세히 표시한다.

### Keyboard Navigation

- 좌우 방향키 또는 `A/D`: 세 선택지 열 사이의 포커스 이동
- 위아래 방향키 또는 `W/S`: 선택 카드와 해당 카드의 리롤 버튼 사이 이동
- `Space`: 현재 포커스된 카드 선택 또는 리롤 실행
- 포커스된 요소는 테두리, 크기 또는 색상 변화로 명확히 표시한다.
- 사용할 수 없는 리롤 버튼은 포커스되지 않거나 실행할 수 없다.
- 레벨업 화면에서는 `Space`를 눌러도 폭탄이 사용되지 않는다.

### Mouse Navigation

- 카드와 리롤 버튼은 마우스로도 동일하게 선택할 수 있다.
- 키보드 포커스와 마우스 호버 상태가 충돌하지 않도록 마지막 입력 장치 기준으로 강조 상태를 갱신한다.

## 5. Manual Pause

- 전투 중 `Esc`를 누르면 게임 상태를 정지하고 일시정지 메뉴를 표시한다.
- 적, 투사체, 아이템, 타이머, 폭탄 쿨타임을 모두 정지한다.
- 전투 정보를 분석하는 용도로 악용하기 어렵게 배경을 어둡게 하고 블러 처리한다.
- 메뉴에는 `계속하기`와 `재시작`을 표시한다.
- 방향키와 `Space`, 마우스로 메뉴를 조작할 수 있다.
- `Esc`를 다시 눌러 계속할 수도 있다.
- 재개 선택 후 `3 → 2 → 1` 카운트다운이 끝나면 전투를 재개한다.
- 카운트다운 중에는 게임 상태를 계속 정지한다.
- 재개 후 1초 동안 일시정지 입력을 비활성화해 연타를 방지한다.
- 레벨업, 보스 페이즈 전환, Victory, Game Over, Time Over 중에는 수동 일시정지를 사용할 수 없다.

## 6. Result Screens

### Victory

- 총점
- 최종 보스 처치 시간
- 남은 시간 보너스
- Restart

### Game Over / Time Over

- 결과 원인
- 생존 시간
- 최종 점수
- Restart

- `Space` 또는 마우스로 Restart를 선택할 수 있다.
