# Enemies

## 1. Common Rules

- 일반 적은 플레이어를 공격 대상으로 한다.
- 플레이어와 일반 적은 서로 물리적으로 충돌한다.
- 일반 적끼리도 서로 물리적으로 충돌한다.
- 일반 적의 접촉 공격은 각 적별 공격 쿨타임을 가진다.
- 공격 쿨타임 중에는 플레이어와 계속 접촉해도 추가 피해를 주지 않는다.
- 일반 적은 피격 시 약한 넉백을 받는다.
- 중간 보스와 최종 보스는 기본 공격과 폭탄의 넉백에 면역이다.

## 2. Hit and Death Feedback

일반 적 피격 시:

- 데미지 숫자를 표시한다.
- 짧은 피격 시각 효과를 표시한다.
- 약한 넉백을 적용한다.
- 일반 적의 HP Bar는 표시하지 않는다.

HP가 0 이하가 되면:

- 즉시 사망 상태로 전환한다.
- 이동, 공격, 충돌을 즉시 중단한다.
- 짧은 사망 시각 효과를 재생한다.
- 경험치 오브젝트는 사망 판정 시점에 드롭한다.
- 사망 연출 종료 후 적 오브젝트를 제거한다.

중간 보스와 최종 보스는 데미지 숫자와 별도의 HP Bar를 표시한다.

## 3. Enemy Types

MVP에서는 서로 다른 특징을 가진 일반 적 3종을 사용한다. 각 일반 적의 특징은 해당 계열의 중간 보스에서 확장되고, 최종 보스는 세 계열의 주요 특징을 조합한다.

### Type 1 - Melee

- 플레이어를 지속적으로 추적한다.
- 플레이어와 접촉하면 피해를 준다.
- 공격 후 개별 공격 쿨타임을 가진다.
- 쿨타임 종료 후 플레이어와 계속 접촉 중이면 다시 공격한다.

### Type 2 - Ranged

- 플레이어에게 접근한다.
- 공격 사거리 안에 진입하면 접근을 멈춘다.
- 공격 시점의 플레이어 위치를 조준한다.
- 플레이어 방향으로 직선 투사체 1발을 발사한다.
- 발사된 투사체는 플레이어를 추적하지 않는다.
- 공격 후 쿨타임을 가진다.

### Type 3 - Regenerating Shield

- 생성 시 공격 1회를 무효화하는 보호막을 가진다.
- 보호막이 활성화된 상태에서 다음 공격의 피해를 완전히 무효화한다.
- 공격을 무효화하면 보호막이 파괴된다.
- 보호막 파괴 후 일정 시간이 지나면 다시 생성된다.
- 활성, 파괴, 재생 상태를 시각적으로 구분한다.

## 4. Enemy Grades

일반 적은 기본 등급과 상위 등급 두 단계로 구성한다.

- 상위 등급은 같은 계열의 기본 등급과 행동 패턴이 동일하다.
- 상위 등급은 HP, 공격 피해, 경험치 가치가 더 높다.
- 이동속도, 공격 쿨타임, 투사체 속도는 기본 등급과 동일하다.
- 상위 등급은 크기, 색상 또는 외형으로 기본 등급과 구분한다.
- 숨겨진 시간 기반 능력치 증가는 사용하지 않는다.

## 5. Time-based Composition

- `0:00 ~ 2:30`: 근접형만 등장하고 상위 근접형 비율이 점진적으로 증가한다.
- `2:30 ~ 5:00`: 원거리형을 추가하고 상위 원거리형 비율이 점진적으로 증가한다.
- `5:00 ~ 7:30`: 보호막형을 추가하고 상위 보호막형 비율이 점진적으로 증가한다.
- 이전 구간의 적 계열과 상위 등급은 계속 등장한다.
- `7:30 ~ 10:00`: 세 계열의 상위 등급 비율과 전체 스폰 밀도가 함께 증가한다.
- 각 구간은 새 계열의 기본 등급을 먼저 학습하게 하고, 상위 등급과 해당 중간 보스로 이어지게 한다.
- 일반 적의 난도 상승은 스폰 밀도, 적 구성, 상위 등급 비율을 중심으로 조정한다.

## 6. Spawn Position

일반 적은 맵 경계 안에 있는 카메라 외곽 스폰 밴드에서 생성한다.

```text
스폰 가능 구역
= 확장된 카메라 영역
- 현재 보이는 카메라 영역
- 맵 바깥 영역
```

- 현재 카메라에 보이지 않는 위치만 사용한다.
- 플레이어와 최소 거리를 확보한다.
- 플레이어가 맵 경계에 가까우면 맵 안쪽에 남은 밴드만 사용한다.
- 유효한 위치가 없으면 화면 안에 강제로 생성하지 않고 해당 스폰을 건너뛴다.
- 맵 내부에 충돌 장애물이 없으므로 장애물 위치 검사는 하지 않는다.

## 7. Spawn Distribution

- 짧은 스폰 주기마다 현재 시간대에 맞는 수의 적을 생성한다.
- 같은 주기에 여러 적이 생성되어도 각각 별도의 위치를 선택한다.
- 스폰 위치끼리 최소 간격을 두고 카메라 외곽의 여러 방향에 분산한다.
- 적은 생성 후 플레이어를 추적하며 자연스럽게 무리를 형성한다.
- 중간 보스가 등장해도 예정된 일반 적 스폰 흐름은 중단하거나 감소시키지 않는다.
- 정확한 주기, 수량, 타입 및 등급 가중치는 플레이테스트로 조정한다.

## 8. Accumulation and Technical Safety

- 정상 플레이에서는 살아 있는 일반 적 수에 따른 체감 가능한 스폰 제한을 두지 않는다.
- 처치 속도가 부족하면 적이 계속 누적되어 압박이 증가한다.
- 오브젝트 풀링을 사용해 반복 생성 및 제거 비용을 관리한다.
- 크래시 방지를 위한 기술적 안전 한도만 설정할 수 있다.
- 안전 한도는 정상 플레이에서 도달하지 않을 만큼 높게 두고 프로파일링 후 결정한다.
- 안전 한도에 도달하면 기존 적을 제거하지 않고 신규 스폰만 임시 중단한다.
- 실제 플레이가 안전 한도에 도달하면 정상 규칙으로 간주하지 않고 성능, 스폰량, 물리 처리를 재검토한다.
