# Growth

## 1. Experience Drop

- 모든 일반 적은 정상적으로 사망하면 경험치 오브젝트를 100% 드롭한다.
- 적 1마리당 경험치 오브젝트 1개를 드롭한다.
- 기본 / 상위 등급에 따라 오브젝트의 경험치 값이 다르다.
- 가치가 다른 경험치 오브젝트는 색상, 크기 또는 외형으로 구분한다.
- 경험치 오브젝트는 플레이어가 획득하기 전까지 필드에 유지된다.
- 시간 전환으로 강제 제거된 적은 경험치 오브젝트를 드롭하지 않는다.

## 2. Experience Pickup

- 플레이어는 일정한 경험치 획득 범위를 가진다.
- 경험치 오브젝트가 획득 범위에 진입하면 플레이어 방향으로 이동하기 시작한다.
- 한번 추적을 시작한 오브젝트는 플레이어가 최초 획득 범위를 벗어나도 추적을 중단하지 않는다.
- 오브젝트가 플레이어에게 도달하면 해당 경험치 값을 획득한다.
- 획득 범위는 패시브로 증가시킬 수 있다.

## 3. Level Up

- 현재 경험치가 다음 레벨 요구 경험치 이상이면 레벨이 상승한다.
- 요구량을 초과한 경험치는 다음 레벨로 100% 이월한다.
- 다음 레벨 요구 경험치는 `10 + (현재 레벨 - 1) x 2`로 계산한다.
- 기본 요구량과 레벨당 증가량은 플레이테스트 결과에 따라 조정한다.
- 경험치 오브젝트가 도달하여 레벨업 조건을 충족하는 순간 게임 시간을 정지한다.
- 정지 중인 적, 투사체, 아이템, 타이머, 폭탄 쿨타임은 진행되지 않는다.
- 선택을 완료하면 게임 시간을 재개하고 추적 중이던 경험치 오브젝트도 다시 움직인다.

### Multiple Level Exception

- 일반적인 플레이에서는 첫 오브젝트가 레벨업을 일으키는 순간 시간이 정지하므로 뒤따르던 오브젝트는 추가 획득되지 않는다.
- 높은 가치의 오브젝트 하나가 이월 경험치까지 포함해 두 레벨 이상을 충족하는 상황은 예외적으로 발생할 수 있다.
- 이 경우 첫 선택을 처리한 뒤에도 경험치가 다음 요구량 이상이면 다음 레벨업 선택을 이어서 처리한다.
- 정상 밸런스에서는 오브젝트 하나로 여러 레벨이 오르는 상황이 자주 발생하지 않도록 조정한다.

### Growth Target

- 평균적인 처치 및 회수 플레이는 성장 구간 종료 시점인 10분에 약 25레벨 도달을 목표로 한다.
- 경험치 패시브와 적극적인 플레이는 더 높은 레벨을 허용한다.
- 정확한 곡선은 플레이테스트로 조정한다.

## 4. Level Up Choices

- 레벨업마다 서로 다른 성장 선택지 3개를 제공한다.
- 선택지는 신규 무기 획득, 보유 무기의 미선택 특성, 패시브 획득 또는 강화로 구성한다.
- 동일한 성장 항목은 같은 화면에 중복 등장하지 않는다.
- 같은 카테고리의 서로 다른 항목이 함께 등장하는 것은 허용한다.
- 최대 단계 또는 완성 상태에 도달한 항목은 일반 추첨과 리롤 후보에서 제외한다.

### Candidate Shortage

- 정상 플레이에서는 항상 3개의 유효 후보를 제공할 수 있도록 콘텐츠 수와 성장 곡선을 구성한다.
- 예외적으로 유효 후보가 2개 또는 1개뿐이면 존재하는 후보만 표시한다.
- 중복이나 최대 단계 항목으로 빈자리를 채우지 않는다.
- 유효 후보가 0개면 최대 성장 상태로 전환하고 경험치 UI에 `MAX`를 표시한다.
- 최대 성장 이후 획득한 경험치는 성장에 영향을 주지 않는다.

## 5. Weapon Growth Rules

- MVP 무기는 기본 무기 포함 총 6종이다.
- 한 판에서 동시에 보유할 수 있는 무기는 기본 무기 1종과 신규 무기 최대 3종, 총 4종이다.
- 무기 슬롯이 가득 차면 보유하지 않은 신규 무기는 후보 풀에서 제외한다.
- 신규 무기를 선택하면 기본 형태로 획득한다.
- 보유한 무기의 미선택 특성이 각각 독립된 레벨업 카드로 등장한다.
- 각 무기는 특성 후보 7개 중 최대 4개를 선택한다.
- 특성은 다시 등장하지 않으며, 네 번째 특성을 선택하면 나머지 미선택 특성 3개도 후보 풀에서 제외한다.
- 복잡한 특성 선행 조건은 MVP에서 사용하지 않는다.
- 상세 무기와 특성은 [Weapons](WEAPONS.md)를 따른다.

## 6. Passive Growth Rules

- 패시브 보유 개수에는 제한이 없다.
- 각 패시브는 최초 획득을 1단계로 하고 최대 5단계까지 강화한다.
- 같은 패시브를 다시 선택하면 해당 효과가 단계적으로 증가한다.
- 5단계에 도달한 패시브는 후보 풀에서 제외한다.

### Passive List

1. **최대 HP 증가**
   - 최대 HP를 증가시킨다.
   - 증가한 최대 HP만큼 현재 HP도 함께 증가한다.
   - 기존에 잃은 체력을 전부 회복하지는 않는다.
2. **이동속도 증가**
   - 플레이어의 기본 이동속도를 단계적으로 증가시킨다.
3. **아이템 획득 범위 증가**
   - 경험치 오브젝트와 리롤 아이템이 추적을 시작하는 범위를 증가시킨다.
   - 아이템의 추적 이동 속도에는 영향을 주지 않는다.
4. **전역 무기 공격력 증가**
   - 모든 자동 무기의 피해량을 증가시킨다.
   - 무기별 피해 특성과 합산한다.
5. **전역 무기 공격속도 증가**
   - 모든 자동 무기의 공격 빈도를 증가시킨다.
   - 무기별 공격속도 특성과 합산한다.
6. **체력 재생속도 증가**
   - 기본 무피격 체력 재생의 초당 회복량을 증가시킨다.
   - 재생 시작까지의 무피격 대기시간은 변경하지 않는다.
7. **경험치 획득량 증가**
   - 경험치 오브젝트가 제공하는 값을 일정 비율 증가시킨다.
   - 소수 결과는 내부적으로 누적하고 UI 표시는 정수로 처리할 수 있다.
8. **피격 후 무적시간 증가**
   - 피해를 받은 뒤 적용되는 전역 무적시간을 증가시킨다.
   - 무적시간에는 상한을 둔다.

## 7. Reroll

- 게임 시작 시 리롤 3회를 보유한다.
- 세 선택지 각각에 개별 리롤 버튼이 존재한다.
- 리롤하면 해당 선택지만 새로운 항목으로 교체되고 다른 두 선택지는 유지된다.
- 리롤 1회마다 보유 횟수 1회를 소비한다.
- 같은 선택지에서 연속 리롤할 수 있다.
- 새 후보는 다른 두 선택지와 중복될 수 없다.
- 방금 제거한 항목은 해당 재추첨에서 다시 등장하지 않는다.
- 최대 단계 또는 완성된 항목은 등장하지 않는다.
- 리롤 횟수가 0이면 리롤할 수 없다.
- 위 조건을 만족하는 교체 후보가 없으면 해당 선택지의 리롤 버튼을 비활성화하고 횟수를 소비하지 않는다.

### Reroll Item

- 중간 보스는 정상적으로 처치될 때 리롤 아이템 1개를 드롭한다.
- 리롤 아이템은 즉시 지급되지 않고 플레이어가 직접 획득해야 한다.
- 획득 범위와 추적 규칙은 경험치 오브젝트와 동일하다.
- 플레이어에게 도달하면 보유 리롤 횟수가 1 증가한다.
