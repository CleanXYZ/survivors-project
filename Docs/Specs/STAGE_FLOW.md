# Stage Flow

## 1. Stage Space

- MVP는 경계가 있는 하나의 넓은 고정 맵을 사용한다.
- 카메라는 플레이어를 따라 이동하고 맵 경계에서 제한된다.
- 플레이어와 적은 외곽 경계를 넘어갈 수 없다.
- 맵 내부에는 충돌 장애물을 두지 않는다.
- 나무, 바위 등 배경 장식은 충돌 없는 시각 요소로만 사용할 수 있다.
- 별도의 보스 방으로 이동하지 않고 같은 맵에서 최종 보스전을 진행한다.

## 2. Growth Phase - 0:00 to 10:00

- 일반 적이 지속적으로 등장한다.
- 플레이어는 적을 처치하고 경험치를 획득한다.
- 레벨업을 통해 무기 특성과 패시브를 성장시킨다.
- 일반 적 종류, 상위 등급 비율, 스폰 밀도가 시간에 따라 증가한다.
- 중간 보스는 `2:30`, `5:00`, `7:30`에 등장한다.
- 상세 적 구성은 [Enemies](ENEMIES.md), 중간 보스는 [Bosses](BOSSES.md)를 따른다.

## 3. Final Boss Transition - 10:00

10분에 도달하면 성장 구간에서 최종 보스전으로 전환한다.

1. 일반 적 신규 스폰을 중단한다.
2. 필드에 살아 있는 일반 적과 중간 보스를 짧은 소멸 연출과 함께 제거한다.
3. 시간 전환으로 제거된 적은 경험치, 리롤 아이템, 처치 점수를 제공하지 않는다.
4. 이미 필드에 드롭된 경험치와 리롤 아이템은 자동 회수하거나 삭제하지 않고 그대로 유지한다.
5. 추적을 시작한 아이템은 계속 추적하고, 시작하지 않은 아이템은 원래 위치에 남는다.
6. 화면에 `WARNING`과 경고 효과음을 표시한다.
7. 플레이어에게서 일정 거리 떨어진 화면 안쪽의 유효한 위치에 소환 마법진을 생성한다.
8. 경고 시간 동안 마법진이 점점 활성화된다.
9. 플레이어는 경고 중에도 자유롭게 이동하고 아이템을 회수할 수 있다.
10. 마법진이 완성되면 최종 보스가 등장한다.
11. 등장 연출이 끝나기 전까지 보스의 충돌, 공격, 피격 판정을 비활성화한다.

`WARNING`은 별도의 정비 기능이 아니라 보스 출현 경고이며, 그 시간에 무엇을 할지는 플레이어가 선택한다.

## 4. Final Boss Phase

- 최종 보스 등장 연출이 끝난 순간 별도의 `10:00` 제한시간을 시작한다.
- 일반 적은 새로 등장하지 않는다.
- 성장 구간에 남은 드롭 아이템은 최종 보스전 중에도 정상적으로 획득할 수 있다.
- 레벨업 선택, 수동 일시정지, 보스 페이즈 전환 연출 중에는 보스 제한시간도 정지한다.
- 제한시간 안에 최종 보스를 처치하면 Victory.
- 제한시간이 0이 되면 Time Over로 Game Over.
- 플레이어가 사망하면 남은 시간과 관계없이 Game Over.

## 5. Score

- 기본 등급 일반 적 처치 시 기본 점수를 획득한다.
- 상위 등급 일반 적은 더 높은 점수를 제공한다.
- 중간 보스는 큰 고정 점수를 제공한다.
- 최종 보스는 가장 큰 기본 처치 점수를 제공한다.
- 10분 전환으로 강제 제거된 적은 점수를 제공하지 않는다.
- 최종 보스를 처치하면 남은 보스 제한시간에 비례한 추가 점수를 제공한다.

```text
최종 보스 획득 점수
= 최종 보스 기본 처치 점수
+ 남은 시간 보너스
```

구체적인 점수 값과 시간당 배율은 스폰량과 전투 밸런스가 정해진 뒤 조정한다.

## 6. Victory

- 최종 보스 사망 연출이 끝난 뒤 Victory 화면을 표시한다.
- 총점, 보스 처치 시간, 남은 시간 보너스를 구분해 표시한다.
- 생존 시간과 처치 통계는 필요에 따라 함께 표시할 수 있다.
- `Restart`로 같은 스테이지를 처음부터 다시 시작할 수 있다.

## 7. Game Over and Time Over

- 플레이어 사망 연출 또는 보스 제한시간 종료 후 결과 화면을 표시한다.
- 사망한 경우 `Game Over`, 시간 초과인 경우 `Time Over`를 표시한다.
- 생존 시간과 최종 점수를 표시한다.
- `Restart`로 같은 스테이지를 처음부터 다시 시작할 수 있다.
- 키보드 `Space` 또는 마우스로 재시작할 수 있다.
